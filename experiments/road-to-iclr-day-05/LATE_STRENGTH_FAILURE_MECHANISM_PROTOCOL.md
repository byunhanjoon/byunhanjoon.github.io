# Post-failure protocol: why source block B breaks the strength-2 gate

Use all material test cells from late source blocks A and B. From the exact
fANOVA summaries define pair energy fraction as `main+pair - main`, residual
higher-order fraction as `1 - (main+pair)`, and their stabilized ratio. Relate
that ratio to `log(four_strength1_residual / strength2_residual)` using
Spearman correlation and a 100,000-permutation two-sided p-value. Report the
individual cells and source means; no threshold or performance gate is added.

The diagnostic supports the interaction-spectrum explanation if the failing
block-B cell/source lies at the higher-order-dominated end and the correlation
is positive. It remains post-failure evidence and cannot rescue the failed
primary gate.
