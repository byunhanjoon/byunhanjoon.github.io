# Row-wise orthogonal-cover reliability protocol

Status: post-confirmation diagnostic, frozen before row-wise outcomes.

For the 25 confirmation cells declared material on validation, compute exact
per-test-row expected residual under strength 2, iid-16, four independent
strength-1 covers, and four full-seed blocks. Report row-improvement fractions
and p50/p95/p99/max residual, first per cell and then pooled with equal cell
weight. No row is treated as an independent dataset replicate.
