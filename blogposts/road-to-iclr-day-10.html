Road to ICLR · Day 10 / 30

Some axes should matter. Others should disappear.

Day 9 found a hidden coordinate grid. Day 10 learned that the right fix was not to erase it, but to return it to the encoder's native frame.

September 2, 2026Han Joon Byun

Suppose a medical table has columns for age and blood pressure. Those axes name different facts. Mixing them changes the question. But after a model turns one blood-pressure value into sixteen internal signals, rotating those sixteen coordinates changes only how the same signal is written.

The hard part is not making every axis irrelevant. It is deciding which axes carry meaning.

INSIGHT 01

There are two kinds of axes. Respect semantic columns; ignore arbitrary coordinate choices manufactured inside each column's embedding.

The safer-looking fix failed

Day 9's guard mixed the original hidden code with a relationship-only view. On the smaller locked panel it looked safe. The broader Day 10 benchmark disagreed: the 95th-percentile cost crossed its preset limit, and the worst normalized cost reached 0.188.

This overturned the simple story. The model did not merely need fewer coordinates. It needed a declared home orientation for the coordinates it already used.

Registration marks for a hidden space

A printer aligns colors using registration marks. The new method does something similar. It sends a fixed, ordered set of example values through the numerical encoder. Their responses reveal how the hidden grid is turned. A matrix factorization then rotates that grid back to the encoder's own native frame—without labels and without training a second predictor.

“Matched” is the crucial word. Bell-shaped RBF features naturally fit a polar/PSD factor. Piecewise-linear PLE features fit a positive-QR/Cholesky factor. The algebra is established prior art; the useful design lesson was to match that machinery to the encoder's native response shape.

RBF ENCODER
polar / PSD

Return overlapping bell responses to their native symmetric frame.

PLE ENCODER
positive-QR / Cholesky

Return ordered piecewise-linear responses to their native triangular frame.

INSIGHT 02

Invariance should preserve the useful convention. Removing an arbitrary choice is safest when the method knows which native structure must remain.

A failed gate is still a failed gate

INSIGHT 03

Audits explain; they do not erase. A later diagnosis can locate the failure and support a cleaner new test, but it cannot retroactively move a locked threshold.

What survived Day 10

The phenomenon itself became hard to dismiss. Across 24 datasets and four backbones, equivalent hidden bases changed predictions in 83 of 95 compatible cells. A current tabular foundation model, TabICLv2, also reacted to equivalent exposed input bases on seven of eight datasets.

THE RESULT, WITHOUT THE SALES PITCHstrong phenomenon · precise remedy · narrow claim

56 / 56new compatible cells passed after the interface freeze
2encoder families with a native-matched construction
Agreement is supported up to measured execution precision—not universal bitwise identity.

One honest boundary: this is not a universal canonicalizer. Rank changes and ill-conditioned features need fail-closed handling; only RBF and PLE received native-matched constructions; exact TabPFN-3 remained unevaluated because its licensed weights were unavailable.

Three ideas I want to keep

01Name the symmetry

Do not demand invariance until you can say exactly which transformation preserves meaning.

02Preserve native structure

Remove the arbitrary frame while keeping the encoder convention that helps learning.

03Keep the failed gates

Negative results and numerical caveats make the surviving claim smaller—and more believable.

Day 10 conclusion. Robustness is not the art of making a model ignore everything. It is the art of drawing the boundary correctly: semantic axes should remain meaningful; arbitrary hidden axes should be returned to a declared native frame.
