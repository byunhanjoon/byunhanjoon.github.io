Road to ICLR · Day 3 / 30

Same information,
different difficulty

The same table has many equivalent representations. A neural pipeline can turn those harmless choices into different functions, training paths, and predictions.

August 26, 2026Han Joon ByunExperiments and results ↗

Day 2 found that cumulative and local encodings span the same piecewise-linear functions, yet produce complementary errors. The broader lesson is that a table does not come with one inevitable representation.

One table has many representations

Move its columns. Rename categories. Change dollars to cents. Rotate an encoded feature block. If each rewrite is reversible and applied consistently, the rows, labels, and prediction task have not changed. Only the spelling has.

This is uncertainty created without changing a single example. If the predictions move around the orbit, the pipeline is partly learning the representation accident. I call the resulting prediction variance schema risk.

The invariance test. A result belongs to the table only to the extent that it survives the representations we have declared equivalent.

Zoom in on one orbit direction

The Day 3 experiments isolate the last rewrite. Start with a feature matrix X and replace it by XB, where B is invertible. Multiplying by B−1 recovers X, and an affine first layer can absorb the same inverse. Information and function class are exactly unchanged.

But a reversible map can turn a round problem into a long, thin one. The condition number κ measures this distortion. Try increasing it below.

This reveals a hierarchy that is easy to blur together: same information does not imply the same initial function, and the same initial function does not imply the same training path.

The vulnerability is broad

I froze 25 tabular tasks, four neural backbones, two κ endpoints, and three paired seeds. After that screen, I separately froze five new datasets as a prospective replication.

The effect survived every backbone. Because X and XB reconstruct one another to roughly 10−14, “one encoding contains more signal” is not available as an explanation. This is a causal failure of coordinate invariance under a fixed training budget.

A representation enters learning twice

The broad experiment still mixed two mechanisms. Ordinary initialization draws the same parameters in both bases, but those parameters describe different functions. Then the optimizer takes coordinate-dependent steps.

This is the main mechanistic result. Matching the initial function removed 94.66% of the severe κ=3,000 damage. The representation was acting as a function prior before learning began. Yet matched predictions drifted from 5.8×10−6 to 0.071 after one AdamW step. The representation was also acting as an optimization metric.

Early drift did not reliably predict final harm on a held-out dataset. That failure is informative: geometry controls how training can move, but the labels decide whether the displaced direction matters. A scalar such as κ or drift can expose vulnerability; it cannot by itself price the consequence.

A more useful mental model. Coordinates choose a prior over functions and a metric over updates. The target then decides which coordinate mistakes are expensive.

Capacity for failure is not typical severity

κ=1,000 is a stress test. It establishes what the training pipeline can be sensitive to, not what ordinary encodings usually cost. Across 150 natural cumulative/local pairs, the median absolute normalized difference was only 0.38%, with no universal winner.

Canonical coordinates are therefore most convincing as a control. They make equivalent tables identical to the network and nearly erase the artificial gap. But they depend on the training sample and on an explicit rank policy. The input-natural update also failed numerically on Adult’s rank-deficient natural pair when its frozen undamped inverse amplified null directions.

The attempted performance method delivered the same warning. Measure-Orbit looked promising on 21 internal datasets, then lost by 0.521% to a compute-matched two-seed TabM ensemble on seven untouched datasets. The phenomenon survived; the proposed recipe did not.

Day 3 conclusion. One semantic table can induce many learning problems. Equivalent representations change both the functions a network is likely to start with and the paths its optimizer prefers. Schema risk measures the resulting wobble; the basis experiments explain one mechanism behind it. That is a reliable diagnostic—not yet a universal performance trick.
