Road to ICLR · Day 4 / 30

A feature is
a domain

A column is not merely a vector of values. It is a place where functions live—with mass, neighbors, and sometimes a geometry worth teaching the model.

August 27, 2026Han Joon ByunExperiments and results ↗

Day 1 found that some numerical columns contain important exact values. Day 2 found that two encodings can contain the same information and still guide learning along different paths. Day 3 widened the problem: even harmless rewrites of the same table can change the final predictor.

Those three observations point to one missing object. We keep discussing vectors that represent a feature, but not the thing being represented.

The Day 4 question. Before choosing coordinates for a feature, can we say what functions of that feature should be easy to learn?

This question led to a mathematical construction, a hopeful experiment, several controls that nearly killed it, and—more importantly—a clearer ICLR direction.

The same dtype can hide different worlds

Imagine four columns, all stored as numbers:

37.2temperaturea point on a line
23:00hour of daya point on a circle
02139ZIP codea name in a bag
37.56, 126.97locationa point on a surface

They share a storage type but disagree about the most basic question: which values are neighbors? For temperature, 20 is between 19 and 21. For an hour, 23:00 is beside 00:00. For a ZIP code, arithmetic adjacency may mean nothing. Latitude and longitude make sense together, not as two unrelated rulers.

This is what I mean by a domain. It is the set of values together with the relationships that survive a change of coordinates. An encoding is only a chart we draw on top of it.

fieldthe values and their meaning→function spacequestions the model can ask→coordinatesone way to compute those questions

Two kinds of structure

Once a field becomes a small function space, two different sources of structure appear.

M
Where does the data live?

If half the rows equal zero, functions near zero should not be measured as if the column were uniform. Mass comes from training examples.

S
Which changes are rough?

On an ordered field, jumping between adjacent values is rough. On a cycle, the first and last values are neighbors. Stiffness comes from meaning.

The proposal is to combine them in one operator:

Klearning geometry
=
Mobserved mass
+
τ Ssemantic smoothness

The scalar τ says how strongly to trust the declared geometry. At τ = 0, the method only normalizes for where observations occur. As τ grows, rapidly oscillating functions become more expensive.

This distinction matters. I am not adding target information or a more expressive basis. For finite τ, the model can represent the same piecewise-linear functions. I am changing the ruler used by initialization and regularization.

‖f‖²K = a⊤(M + τS)aThe coordinates a may change when we redraw the chart. The cost assigned to the underlying field function should not.

I call this construction FieldRiesz, after the Riesz map that turns a notion of function size into coordinates. The name is less important than the promise: rewriting the same field should not silently rewrite its learning prior.

The wrong geometry is the real baseline

A smooth basis can win for uninteresting reasons: better scaling, different support points, or extra parameters. Ordinary piecewise-linear embedding (PLE), for example, turns a value into overlapping local bins. So the useful comparison is not “new encoding versus old encoding.” It is a ladder of increasingly annoying controls.

If mass alone wins, the discovery is conditioning. If correct and randomized geometry tie, the discovery is merely a favorable spectrum. Meaning earns credit only for the gap that remains after both controls.

The experiment split into two stories

The broad performance story was disappointing. I compared against RAPLE, my stronger existing pipeline: an out-of-fold tree anchor followed by learned residual features and a neural model. Across five datasets, three backbones—MLP, ResNet, and TabM—and three seeds, there are 45 paired cells.

The mechanism story was more encouraging. California Housing and Weather were the two datasets where the pilot suggested meaningful geometry. I repeatedly randomized the field-function modes while preserving the complete generalized spectrum relative to empirical mass—in plain language, the control kept the same menu of smooth and rough frequencies but reassigned what those frequencies meant. Correct geometry won 80/90 control comparisons (+0.90%) across MLP, ResNet, and TabM. Averaging the five controls within each dataset–model–seed cell gave 18/18 wins.

That middle result sounds stronger than it is. California and Weather were selected after the broad pilot, so 80/90 is a stress test of the suspected mechanism—not 90 independent discoveries and not a confirmatory p-value. The independent, predeclared spatial replication on chronological King County did not reproduce California: 2/9 wins versus raw RAPLE, and −0.03% against the averaged exact-spectrum control.

The result that survived. Meaningful mode assignment can matter after support, dimension, mass, and spectrum are fixed. I do not yet know a reliable, label-safe rule for when that difference improves prediction.

In ordinary language: find the simplest schema-respecting correction to what the strong baseline still gets wrong. At τ = 0, this is familiar Galerkin residual regression. Adding S is classical smoothing. The potential contribution is not the matrix inverse; it is the disciplined use of declared tabular semantics, chart covariance, and controls inside modern tabular pipelines.

The method should begin with a diagnosis

The negative results changed my preferred paper. A universal encoder asks one intervention to help everywhere. But Day 3 already produced a way to learn which arbitrary choice is hurting a pipeline.

OrbitANOVA remains the primary ICLR direction. Its shortest description is: arbitrary schema spelling is an unreported hyperparameter. Refit a complete pipeline under meaning-preserving spellings, align the outputs, and measure how much its prediction wobbles.

SR = Ex,z ‖Pz(x) − P̄(x)‖²For squared and Brier loss, this schema risk is exactly the loss removed by averaging predictions over equivalent spellings. It can therefore be measured without evaluation labels after fitting.

The decomposition makes the intervention conditional:

dominant source of wobblecandidate response
feature order→symmetrize or average a balanced cover
category or target IDs→use an equivariant interface
within-field chart→FieldRiesz or a covariant optimizer
schema × tuning→pool validation over spellings, then freeze
nothing stable→abstain or use a generic ensemble

This synthesis gives FieldRiesz a better role. It is not “the new preprocessing method.” It is one closure the audit may choose when within-field coordinates dominate the risk. The scientific question becomes whether structured attribution chooses a better action than simpler alarms.

What is actually new?

The mathematical ingredients have deep histories. Finite elements already use mass and stiffness matrices. Splines and graph Laplacians already express smoothness. Functional ANOVA already decomposes effects. Bregman information already relates prediction dispersion to loss. Recent tabular work studies numerical embeddings, preprocessing robustness, equivariance, strong tuned baselines, nearest-neighbor models, ensembles, and foundation models.

EstablishedThe pieces

Mass, stiffness, smoothing, Riesz maps, variance identities, fANOVA, and equivariance.

Plausibly newThe closed loop

Declare equivalent schemas, price complete-pipeline risk, attribute it, and choose a matched repair.

Still unearnedThe payoff

A repair policy that transfers across datasets and improves loss at matched compute.

I would rate the direction about 3.5/5 ready. If submitted today, my own decision would be weak reject: the composition is differentiated, but its broad prevalence and audit-guided action are promises. The bottleneck is demonstrated payoff, not another decorative theorem.

The panel should contain 12–15 datasets and modern families: MLP, ResNet, FT-Transformer, TabR, TabM, and—where their interface permits it—tabular foundation models. All model families from one dataset stay in the same outer fold. The dataset, not each seed or backbone, is the replication unit.

OrbitANOVA earns the larger claim only if its attribution changes which action is selected and improves the held-out loss–stability–resource frontier. If it does no better than a pairwise alarm, the honest reviewer summary is “PREF plus ANOVA,” and the project should shrink.

Day 4 conclusion. A feature is not the coordinates preprocessing happened to emit. It is a domain on which the model learns functions. Sometimes the domain has useful geometry; sometimes inventing one is harmful. The promising paper is not a method that always trusts geometry. It is an audit that learns which arbitrary choice matters, chooses the smallest repair, and proves that choice useful somewhere it has not already looked.
Technical and statistical boundaries

All support nodes, mass matrices, and stiffness operators use training covariates only. Residual-Riesz uses labels only through out-of-fold anchor residuals, so a row never contributes its label to its own residual. Finite-τ charts span the same nonredundant centered piecewise-linear function space. Parameter counts are matched analytically. Node-permuted controls preserve ordinary stiffness spectra; the harder M-isospectral controls preserve generalized spectra relative to empirical mass. The 80/90 count reuses 18 fitted semantic cells against five controls each and is conditional on post-pilot dataset selection. King County was the predeclared spatial replication. Chart covariance is claimed for represented functions, penalties, and transported metric updates—not for identical AdamW trajectories under every rotation. The public numbers are research-pipeline results, not an official full TabReD leaderboard submission.
