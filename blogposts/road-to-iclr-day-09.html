Road to ICLR · Day 9 / 30

The model built its own grid—and then trusted it.

A number entered the model. It became sixteen internal signals—and acquired a new, arbitrary coordinate system.

September 1, 2026 · updated September 2Han Joon Byun

A table is a description of reality. A medical model never meets a patient; it sees columns. This raises a simple test for dependability:

If two descriptions contain the same information, should the model care which one we chose?

Day 9 began by turning the coordinate grid under a dataset. Then a later experiment revealed the more interesting twist: modern models quietly build new coordinate grids inside themselves.

The first clue: turn the grid

Drag the slider. The points rotate together, preserving every distance and relationship. Only the directions used to describe them change.

Across 11 real datasets and five model families, nearly three quarters of the model–dataset pairs changed enough to cross a threshold fixed before the test.

SAME FACTS, DIFFERENT GRIDnearly 3 in 4

INSIGHT 01

A representation is not neutral. A learner never sees “the thing itself.” It sees one coordinate description of it.

Then the model builds another grid

Many tabular models do not use a number such as 0.62 directly. They first translate it into a row of internal signals—rather like sixteen lights, each responding to a different neighborhood of the number line. This is a numerical embedding.

This second grid matters because the model can trust its orientation just as easily as it trusted the original columns. Worse, giving the embedding more dimensions creates more directions in which that accidental preference can hide.

A 16-coordinate code has many equivalent orientations.

INSIGHT 02

Capacity creates coordinate choices. A wider representation can express more—but it also offers more arbitrary directions for learning to favor.

Perfect stability can still be wrong

A relationship-based description can erase the hidden grid completely. That achieved perfect stability. But it sometimes damaged prediction badly: an arbitrary-looking direction had become a useful shortcut.

LEAVE IT ALONEflexiblebut the hidden grid remains
FORCE PERFECT STABILITY100% stablerare, severe prediction failures
ADD A SAFETY BRAKEas stable as safeback away when quality suffers

A fixed compromise did not solve this either. The same 75% mixture that looked good on average still produced large misses on a few new datasets. The missing idea was not another representation. It was a guard.

A dial with a brake

The guarded method starts with a strong dose of the stable view. A held-out practice set asks whether prediction quality stays inside a preset safety line. If not, the method steps down—75%, 50%, 25%, then all the way back to the original view.

INSIGHT 03

Stability needs both a location and a brake. Apply it where the arbitrary coordinates are created, then retreat when the task says they were useful.

The method was frozen before testing on twelve untouched datasets. In most cases the guard kept the strong setting. In a few, it chose a smaller dose or returned to the original model.

The strongest result was not “maximum stability always wins.” It was “use the strongest stability that passes a safety check.”

One honest limit: this is a strong result from one locked new-data panel, not a final verdict. The next test is to repeat the unchanged method on a second independently locked panel.

Three ideas I want to keep

01Look beyond the input table

Models can manufacture arbitrary coordinates after the data enters the network.

02Test hidden descriptions

Turn hidden coordinates without changing their meaning. The answer should survive this unit test.

03Guard the remedy

Robustness is safest when the model can retreat before stability harms the task.

Day 9 conclusion. The coordinate system is not the territory—even when the model invents that coordinate system itself. The most promising remedy acted exactly where the hidden grid was created, replaced directions with relationships, and kept a safety brake connected to prediction quality.
